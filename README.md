# 정신의학·DSM-5 랭크전

정신건강전문요원(정신건강사회복지사) 수련 필기 대비 퀴즈 게임.
로드맵: 레벨테스트 → 진단 → 맞춤 학습 → 승급 시험 (진행 중)

## 구조
- `data/questions.json` 문제은행 (영역, 난이도 1~3, 출처, 검수 상태)
- `src/shell.html`, `src/engine.js` 화면과 게임 로직
- `build.py` 위 파일을 합쳐 `index.html`(단일 파일, 오프라인 실행)을 만듦
- `sw.js`, `manifest.webmanifest` PWA(홈 화면 설치, 오프라인)

## 문제 추가·수정
1. `data/questions.json`에 문항 추가 (`st`: 검수 전 `draft`, 검수 완료 `reviewed`)
2. `python3 build.py` (형식 오류, 중복, 정답·오답 겹침을 검사)
3. 커밋·푸시

## 원칙
- DSM-5 원문과 출판 교재 문장은 옮기지 않고, 사실만 가져와 새 문장으로 출제
- 문항마다 출처 표기, 검수 전 문항은 게임에 "검수 전" 표시
- 문제 오류는 게임 안의 🚩 문제 신고(이 저장소 Issue)로 접수
